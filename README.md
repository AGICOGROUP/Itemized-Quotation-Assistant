# Itemized Quotation Assistant

An agent skill that turns a supplier cost table into a fully itemized export quotation — deterministic markup rules, export-tax refund handled per item, and a calculation trail you can audit line by line.

It does not produce a single lump-sum price. It produces a structure: every line has a rule, every rule has a reason, and the total can be recomputed from the line items.

---

## The three problems it solves

**1. Tax and markup get mixed together.** Refund is derived from the untaxed cost, and services or freight usually qualify for no export refund at all. Mixing the two systematically overstates or understates the price.

**2. Special markup lives in people's heads.** "Charge 15% on these, keep those at cost" is remembered by a person, not by a system — and it changes when the person changes.

**3. The quote cannot be defended.** A total price alone cannot answer "why is this line 76% above cost?" in front of a customer.

This project fixes all three with a fixed pipeline: a parameter form collects decisions, a compact submission string carries them back, hashes bind the confirmation to the calculation, and the output is a four-section report plus a three-sheet Excel workbook.

## How it works

**One presentation contract.** The confirmation form has exactly one shape, generated by script and locked by two fingerprints — a template hash and a *shape* hash computed over a rendered sample with all project data normalized away. Any drift aborts before a file is written. The agreement is machine-readable in `contracts/form-presentation.md`, and `check_contract.py` verifies the fence identifier, size cap, slot count and both hashes against the template, the lock files and a live sample render.

**No natural-language parameters.** The form emits a 13-field submission string (multi-select options are bitmap-encoded). The backend decodes it; `input.json` and `confirmation.json` are bound by SHA256, so a single changed digit makes the calculator refuse to run.

**The pricing model is explicit.**

```
refundable cost      = total cost − non-refundable items
assumed refund       = Σ item cost ÷ (1 + input VAT rate) × refund rate
cost after refund    = total cost − assumed refund + extra costs
total quote          = cost after refund ÷ (1 − margin − commission)
item quote           = fixed-markup items first; remainder allocated pro rata by original cost
```

**Auditable deliverables.** Every run produces four sections — total quote, parameters used, total price derivation, final itemized table — plus an Excel workbook with three sheets (itemized quote / parameters and FX / calculation process).

## Scope and limits

- **Covers:** cost-table transcription checks, per-item markup, export-tax refund, exchange rate (live or fixed), Excel delivery.
- **Does not promise:** closing price, customer acceptance, realized margin. The tool computes what you decided, precisely and visibly.
- **Host boundary:** the confirmation form is a host-rendered widget; it renders only inside the client that generated it, and degrades to source code if forwarded elsewhere. The project deliberately does not work around this with a second presentation medium — one form, one shape, no alternatives.
- **Input shape:** an itemized cost table (Excel/CSV or screenshot). Lump-sum quotes with no breakdown must be split at subsystem or process level first.

## Tests

34 regression tests cover the pricing model, the submission codec, the form renderer, and the safety gates — including two negative tests that a hand-edited template and a drifted contract must both be refused with no output file written.
